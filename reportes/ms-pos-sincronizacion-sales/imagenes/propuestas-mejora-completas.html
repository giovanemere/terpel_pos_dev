  • FastAPI: Framework web ultra-rápido y liviano

  • Redis: Cache + broker para Celery
  • SQLAlchemy: ORM async para PostgreSQL
  • Pydantic: Validación de datos automática
  • Flower: Monitoreo de Celery en tiempo real
